# Velocity fonts

Velocity self-hosts the variable fonts used by the theme and keeps system sans-serif fallbacks in the font stacks.

- `Manrope-Variable.woff2` is used for LTR interfaces and is licensed under the SIL Open Font License 1.1 in `Manrope-OFL.txt`.
- `Alexandria-Variable.woff2` is used for RTL interfaces and is licensed under the SIL Open Font License 1.1 in `Alexandria-OFL.txt`.
